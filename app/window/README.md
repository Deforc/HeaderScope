# Главное окно HeaderScope

Окно использует общий `ScanResult` и существующий `DependencyGraph`. Бэкенд и
каталог `app/graph_view` не изменяются.

## Запуск

Нужны CMake 3.21+, компилятор C++20 и Qt 6.5+ (Widgets, Concurrent; Test для тестов).
Из корня репозитория:

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6.x/kit
cmake --build build
ctest --test-dir build --output-on-failure
```

На Windows запустите `build/app/window/HeaderScope.exe` (либо подкаталог Debug/Release).
На macOS — `build/app/window/HeaderScope.app`. Для сборки без тестов используйте
`-DBUILD_TESTING=OFF`. При запуске нужны библиотеки Qt из выбранного комплекта.

Нажмите «Папка…» или «compile_commands.json…» — анализ запустится сразу после выбора.
Затем выберите файл слева: справа появятся его подключения и прямые/косвенные
потребители. Наведите курсор на зависимый файл, чтобы увидеть полную цепочку. Двойное
нажатие на строку зависимости или нажатие на вершину графа выбирает файл. Поиск
фильтрует список, колесо масштабирует граф, перетаскивание перемещает его.

Для реального проекта включите `HEADERSCOPE_BUILD_SCANNER=ON` и настройте LLVM/Clang
по корневому README. Выберите папку с `compile_commands.json` либо сам файл в
каталоге сборки и нажмите «Анализировать». Без сборщика анализ выдаёт
объяснение в диагностике. Неполный результат остаётся доступен; после неудачи
старые результаты очищаются. Одновременный повторный запуск блокируется.

## Точка интеграции графа

`GraphPlaceholder` — временное представление на QGraphicsView внутри модуля окна.
Оно не реализует задачу Алексея целиком. Для подключения будущего виджета из
`HeaderScope::graph_view` замените этот тип и сохраните три операции:

- `setResult(const ScanResult&)` — передать результат анализа;
- `selectFile(const std::filesystem::path&)` — подсветить выбранный файл;
- сигнал `fileActivated(const QString&)` с полным UTF-8 путём — выбрать файл в окне.

`fitGraph()` используется кнопкой «Уместить граф». `highlightChain(...)` подсвечивает
набор рёбер цепочки до зависимого файла.
Проверка нового подключения остаётся задачей полноценного виджета.

## Циклы

Вкладка «Циклы» перечисляет все простые циклы по группам, найденным алгоритмом
Тарьяна. Счётчик на вкладке показывает число циклов. Все циклы подсвечены
одновременно, рядом с каждой цепочкой справа показан её цвет. Длинные цепочки
переносятся на несколько строк. Выбор цепочки выделяет её на графе, кнопка
«Показать все циклы» возвращает общий вид с цветными полосами на общих рёбрах.
Чтобы получить цикл на демопроекте, сконфигурируйте его с `-DHEADERSCOPE_DEMO_CYCLE=ON`.

Анализ вызывается через QtConcurrent без захвата окна; QFutureWatcher доставляет
результат в главный поток. Сборщик не предоставляет отмену: повторный запуск
заблокирован до завершения, а завершение процесса может дождаться рабочего потока.
Промежуточный процент не показывается, поскольку API сборщика его не сообщает.

Тесты `window` проверяют зависимости `b.h`, частичный результат, очистку после
ошибки, отсутствующую базу команд и показ цикла (тесты подают фикстуру через `showResult`). Workflow
`Qt main window` собирает и проверяет окно в двух конфигурациях: со сканером и без.
